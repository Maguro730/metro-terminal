# 地铁智能出行查询终端

这是城市轨道交通站台嵌入式智能查询终端的网页交互原型，默认场景为广州地铁嘉禾望岗站。

## 当前阶段

当前阶段已完成：

- 首页、线路查询页和地铁周边页拆分为三个独立 HTML 页面；
- 首页功能卡片、页面返回按钮和两个功能页右上角互相跳转；
- 2号线、3号线（主线与北延段）和14号线（主线与嘉禾望岗—乐嘉路段）的本地站点数据；
- 出发站默认使用嘉禾望岗，也可以在查询页更换出发站进行测试；
- 线路查询和地铁周边页面使用自定义滑动站点选择面板，按中英文首字母分组，并提供右侧 A–Z 快速滚动索引；
- 按站数和换乘次数计算可解释路线；
- 显示乘车方向、途经站点和换乘步骤；
- 中英文界面切换，并用浏览器本地存储保持语言选择；
- 所有当前线路站点都有基础周边资料展示；
- 线路查询页与地铁周边页可以在右上角互相切换；
- 使用用户提供的广州地铁标志图片作为本地品牌图，页面不依赖外部图片。

本阶段不接入实时列车、票价、运营时间和出口距离。周边资料用于毕业设计原型展示，具体出口和步行路线仍应以现场导向和官方信息为准。

## 运行方法

1. 打开本文件夹。
2. 双击 `index.html`。
3. 点击“线路查询”或“地铁周边”，确认会进入独立页面。
4. 在线路查询页分别选择出发站和目的地，点击“查询路线”。
5. 查看线路、方向、途经站点、站数和换乘次数。
6. 点击右下角“中文 / English”，检查当前结果和页面内容同步切换。
7. 在两个功能页之间点击右上角按钮，检查可以互相跳转。

本项目不需要安装软件，也不需要联网。

## 文件说明

- `index.html`：首页。
- `route.html`：线路查询页。
- `nearby.html`：地铁周边页。
- `css/style.css`：颜色、布局、触摸按钮和竖屏适配。
- `js/app.js`：站点选择、路线计算、周边渲染和跨页面语言切换。
- `assets/guangzhou-metro-logo.jpg`：用户提供的广州地铁标志图片。
- `js/data/metro-data.js`：线路和站点顺序数据。
- `js/data/nearby-data.js`：当前线路站点的周边地点数据。

## 数据核查说明

线路数据按广州地铁公开资料和广州市政府、交通运输部门公开信息整理。14号线南段使用2025年9月29日开通的嘉禾望岗—乐嘉路段；广州火车站方向的后续延伸不在本阶段数据中。正式提交前应再次对照广州地铁最新线路图和车站英文标识复核。
